# Aya Berday — Portfolio V6

Site statique : aucun npm ni build nécessaire.

## Aperçu local
Ouvrir un terminal dans ce dossier (celui contenant index.html) :

```sh
python -m http.server 8000
```

Ouvrir http://localhost:8000 et effectuer Ctrl+F5 si nécessaire. Si le port est déjà utilisé, arrêter l’ancien serveur avec Ctrl+C ou utiliser le port 8001.

## Nouveautés
Nouvelle composition noir / vert néon, portrait encadré, orbites animées, alertes simulées, trois études de cas mises en avant, terminal interactif sans exécution de code, mode lecture recruteur, dix domaines/outils et plateformes, aperçu Oracle rendu depuis le PDF original, navigation des certificats. Les 15 pages de projets et les justificatifs sont conservés. L’introduction utilise l’image fournie précédemment (GIF à une image), animée en CSS. Les deux nouvelles vidéos sont des références de design, pas des réalisations d’Aya ni des médias intégrés.

## Accessibilité
Intro passable, touche Échap, commandes clavier, préférences de mouvement réduit, boutons de pause et mode lecture recruteur. Défilement automatique des projets uniquement sur activation explicite. Alertes décoratives annoncées comme simulations.

## GitHub Pages / Vercel
Copier TOUT le contenu du dossier à la racine du dépôt : index.html, fichiers CSS/JS/JSON, assets, projets et .nojekyll. GitHub Pages : branche main, dossier racine. Pour Vercel : projet statique, sans commande de build, répertoire de sortie racine.

## Contenu
Ne pas ajouter de scores, rangs, missions ou résultats non confirmés. TryHackMe et SecDojo sont présentés comme plateformes de pratique sans profil ni classement inventé. Forensic : en formation. GRC : enseignements, conception Zero Trust et exercice Kasbah. L’aperçu Oracle pointe vers le justificatif PDF original.

## Contrôles
Liens internes et présence des assets vérifiés. Interactions et mise en page vérifiées en navigateur desktop et dans un viewport mobile de 390 px. Aucun déploiement public réalisé pour cette version.
