TRYHACKME / LAB 03 · TERMINÉ

Search Skills

OSINT / Reconnaissance passive / Collecte d’informations

Débutant · 6 tâches terminées · 40 points

01 / LAB REPORT

Objectif

Développer les compétences de recherche technique et de collecte d’informations utiles aux investigations de cybersécurité et aux tests d’intrusion. Comprendre comment les moteurs de recherche, opérateurs avancés, ressources spécialisées et documentations soutiennent une évaluation de sécurité.

02 / LAB REPORT

Environnement et ressources

TryHackMe · Search Skills · Débutant. Exercices dans le navigateur, moteurs de recherche, informations publiques et documentation technique. Techniques étudiées : OSINT, requêtes avancées et reconnaissance passive.

03 / LAB REPORT

Collecte d’informations

Identifier les informations pertinentes avant une évaluation technique permet de comprendre l’environnement publiquement visible d’une cible. Reconnaissance passive : collecter depuis des sources publiques sans sonder directement l’infrastructure cible. Reconnaissance active : interagir avec les systèmes autorisés pour identifier services, technologies et faiblesses potentielles.

05 / LAB REPORT

Reconnaissance passive et footprinting

Explorer l’empreinte numérique à travers les pages et documents publics, les informations organisationnelles et techniques, les noms et versions de logiciels divulgués, les domaines, les infrastructures visibles et les avis de sécurité. Une information exposée ne constitue pas automatiquement une vulnérabilité.

06 / LAB REPORT

Évaluation des informations

Une ancienne version mentionnée dans un document peut justifier une recherche complémentaire. Le document ne prouve ni que cette version est toujours déployée ni que le système est vulnérable. Une évaluation professionnelle nécessite des vérifications dans un périmètre autorisé.

07 / LAB REPORT

Documentation et notions clés

Consulter la documentation officielle des éditeurs, les avis de sécurité, les fiches CVE, la National Vulnerability Database du NIST et les bases de connaissances techniques. OSINT : renseignement issu de sources publiques. Footprinting : collecte sur la présence numérique. Google Dorking : utilisation d’opérateurs avancés. Surface d’attaque : systèmes et ressources potentiellement exposés. CVE : identifiant d’une vulnérabilité divulguée. NVD : base d’informations sur les vulnérabilités publiquement divulguées.

08 / LAB REPORT

Considérations de sécurité

  1. Une information publique n’est pas automatiquement sensible.
  2. Identifier une technologie ne prouve pas sa vulnérabilité.
  3. Les documents historiques peuvent être obsolètes.
  4. Vérifier les constats avant de signaler une faiblesse.
  5. Limiter les tests actifs au périmètre explicitement autorisé.
  6. Traiter les données personnelles de façon responsable.
09 / LAB REPORT

Enseignements

Information publique → Hypothèse de sécurité → Vérification technique → Constat confirmé. Cette démarche réduit les faux positifs et améliore la précision des rapports. La recherche fiable et la compréhension de la documentation complètent les outils techniques du pentest.
